# 📚 School Attendance Pro

Система учета посещаемости для школы с синхронизацией через Google Таблицы.

## 🚀 Быстрый старт

Откройте: `https://mahmud997.github.io/school-attendance/`

**Логины:**
- Завуч: `zavuch` / `123`
- Дежурный: `teacher` / `123` (могут входить несколько человек одновременно)

## 📋 Возможности

- Отметка посещаемости в реальном времени
- Несколько дежурных одновременно под одним логином
- Завуч видит все изменения онлайн
- Статистика по классам и ученикам
- Экспорт отчета в CSV
- Автоматическая синхронизация через Google Таблицы

## 🛠️ Настройка

1. Создайте Google Таблицу с листами: `students`, `records`, `users`
2. Вставьте код из `script.gs` в редактор скриптов
3. Опубликуйте как веб-приложение
4. Замените `SCRIPT_URL` в `index.html`
