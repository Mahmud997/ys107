# 📚 School Attendance Pro

Готовая локальная/GitHub Pages система учёта посещаемости школы с синхронизацией через Google Таблицы и Google Apps Script.

## Возможности

- 🔐 Авторизация по ролям: завуч / дежурный
- 👥 Несколько дежурных одновременно
- ☁️ Общая серверная сессия через Google Apps Script
- 🔄 Автосинхронизация каждые 5 секунд
- 📝 Одна актуальная отметка на ученика за день: повторное сохранение обновляет запись
- 👨‍🎓 Добавление и удаление учеников
- 🗑️ Удаление всех записей посещаемости с кнопки завуча
- 📊 Статистика за день, по классам и ученикам
- 🔎 Поиск по ФИО и классу
- 📥 Экспорт CSV и Excel `.xlsx`
- 🖨️ Печать журнала
- 📱 Адаптивный интерфейс
- 🛡️ Серверная проверка роли для административных операций
- 🧹 Автоматическое удаление устаревших онлайн-сессий

## 1. Google Таблица

Создайте таблицу и листы:

- `users`
- `students`
- `records`
- `sessions`

В Apps Script вставьте `script.gs` и один раз запустите функцию `setupSheets()`.

### Заголовки

`users`:

```text
login | password | role | name
```

`students`:

```text
id | name | class
```

`records`:

```text
id | studentId | date | time | status | note | teacher | updatedAt
```

`sessions` создаётся автоматически.

## 2. Пользователи

Добавьте, например:

```text
zavuch | 123 | zavuch | Завуч
teacher | 123 | teacher | Дежурный
```

> Для реального внедрения рекомендуется использовать индивидуальные пароли и не хранить их в открытом виде. Текущая версия сохраняет совместимость с простой таблицей пользователей.

## 3. Публикация Apps Script

В Google Apps Script:

**Deploy → New deployment → Web app**

Параметры:

- Execute as: **Me**
- Who has access: **Anyone**

Скопируйте URL Web App и вставьте его в `SCRIPT_URL` внутри `index.html`.

## 4. GitHub Pages

Загрузите `index.html` и `README.md` в репозиторий. GitHub Pages будет обслуживать только интерфейс. Google Apps Script остаётся серверной частью.

Схема работы:

```text
GitHub Pages
     ↓
 index.html
     ↓ POST
Google Apps Script
     ↓
Google Таблица
```

## Важные исправления по сравнению со старой версией

1. Онлайн-пользователи больше не хранятся только в `localStorage`.
2. У каждой серверной сессии есть токен и срок жизни.
3. `resetAll()` действительно очищает записи.
4. ID записи создаётся сервером и возвращается клиенту.
5. Повторная отметка ученика за тот же день обновляет существующую запись вместо создания дубля.
6. Административные операции проверяются на сервере.
7. Добавлены Excel `.xlsx`, CSV и печать.
8. Добавлена автоматическая очистка старых сессий.

## ⚠️ Безопасность

Google Apps Script Web App — удобный вариант для школьного проекта, но это не полноценная корпоративная IAM-система. Для серьёзного внедрения нужны индивидуальные учётные записи, хеширование паролей, аудит действий и более строгая серверная авторизация.
